# CodeAlpha Hangman Game

## About the Project

This is a simple Hangman word guessing game developed using Python.

The computer randomly selects a word, and the player has to guess the word one letter at a time.

## Features

- Random word selection
- Letter guessing
- Tracks wrong guesses
- Maximum 6 wrong guesses
- Displays win or game-over message

## Technologies Used

- Python
- Random module
- Loops
- Conditional statements
- User input

## How to Run

Run the following command in PowerShell:

python .\hangman_game.py
