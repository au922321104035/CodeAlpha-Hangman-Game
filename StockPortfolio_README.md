# Stock Portfolio Tracker

## About the Project

This is a simple Stock Portfolio Tracker developed using Python.

The program calculates the total value of a stock portfolio based on the number of shares and stock prices.

## Features

* Stores stock names and quantities
* Uses predefined stock prices
* Calculates individual stock values
* Calculates total portfolio value
* Displays the portfolio details clearly

## Technologies Used

* Python

## Example Stocks

* AAPL
* TSLA
* GOOGL

## Example Output

Total Portfolio Value = $2105

## How to Run

Run the following command in the terminal:

```bash
python stock_portfolio.py
```
